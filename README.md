Yes, OmniPatch is designed to be safe. It only modifies license verification files without altering core application functionality. However, as with any patching tool, use at your own discretion.

### Which AI applications are currently supported?

OmniPatch supports ChatGPT, Claude, Perplexity, Microsoft Copilot, Cursor, GitHub Copilot, Devin, and JetBrains AI Assistant.

### How often is OmniPatch updated for compatibility?

We aim to release updates within 48-72 hours after major application updates that break compatibility. Check the Releases page for the latest versions.

### Will this work with my existing account and data?

Yes, OmniPatch activates features on your existing accounts. It does not create new accounts or affect your saved data, conversations, or projects.

### Do I need to disable my anticomponent or firewall?

Some security software may flag patching tools. If you encounter false positives, you may need to create an exception, but we recommend only using trusted sources.

### Can I use OmniPatch on macOS or Linux?

Currently, OmniPatch is only available for Windows desktop applications. Cross-platform support may be considered for future versions.

### Does this require a permanent internet connection?

No, once the activation is applied successfully, it works offline. However, you'll need internet for the AI applications themselves to function normally.

### Is this legal to use?

OmniPatch is a proof-of-concept tool for educational purposes. Users are responsible for complying with the terms of service of any applications they modify.
